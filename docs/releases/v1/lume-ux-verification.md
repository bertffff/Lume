## Визуальные свидетельства

- Статические визуальные состояния: 180 просмотров в Cinema, Gruvbox и TeleRave-v2; размеры по ширине `360`, `390`, `430`, `1440`; светлая, тёмная и системная с эмуляцией светлой ОС. После исправления шапки TeleRave горизонтальное переполнение не наблюдалось. Динамическое переключение ОС со светлой на тёмную проверено в Chromium для всех трёх стилей и тестом `useAppearance`.
- Живой Playwright в `1440×900` и `390×844`: изолированный пользователь открывает комнату из мастера, получает шестисимвольный код, проверяет пустой плеер, профиль и поповер с реальными строками из БД. Контрольные PNG прочитаны инструментом `read`; временные снимки не являются эталонами в Git.
- Для повторного запуска проверки с живыми снимками можно передать `LUME_UX_SCREENSHOT_DIR` вне рабочего дерева. Просмотр `?shot=room` — контроль пустого состояния, не доказательство работы сокета, очереди или голоса. Медиасвязь с реальным LiveKit Cloud не проверялась в локальном контуре.

Полный локальный набор прошёл. Действующая Telegram-среда и LiveKit Cloud не проверялись; запуск опирался на локальные сервисы и заглушки интеграций. Миграция в продакшене не выполнялась; порядок её применения описан в [руководстве по замене приглашений](room-invite-cutover.md).
