## Новые функции из Telerave-v2 (в этом проходе)

- **Управление очередью**: убрать, переставить, «включить сейчас» (API `DELETE/POST /rooms/:id/queue/:itemId…`, сокеты `queue:remove|move|play`, интеграционный тест `queue-manage.test.ts`, e2e `queue-manage.spec.ts`).
- **Поиск видео внутри комнаты** с кнопкой «В очередь» (док → Очередь).
- **Чат**: ответ на сообщение (цитата) и реакции-чипы с быстрым выбором 👍 ❤️ 😂 (e2e `chat-reply-react.spec.ts`).
- **Скачать мои данные** (GDPR) в настройках.
- Главная Gruvbox — настоящая tmux-сессия; главная TeleRave — хаб в одну колонку.
