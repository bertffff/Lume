# Главная (Кинозал и TeleRave-v2 до своей раскладки)

**Задача пользователя.** За две секунды понять, куда идти: продолжить начатое, создать комнату, войти по коду или зайти к друзьям. Потом выбрать открытую комнату.

**Главное действие.** «Создать комнату» — единственная акцентная заливка на экране. «Продолжить» — крупный постер без заливки; вход по коду и «Зайти» у друзей — вторичные кнопки. Гостю главное действие — «Войти»; тогда «Создать комнату» вторична.

**Иерархия сверху вниз.** Приветствие (28/36) и одна строка о друзьях → три плитки одной высоты (Продолжить · Создать · Вход по коду) → «Открытые комнаты» с фильтрами → сетка постер-карточек с бесконечной прокруткой. Справа колонка 360 px: друзья онлайн, уровень, напоминания, сезон, честная статистика.

**Плотность и сетка.** Шкала отступов 4/8/12/16/24/32. Контейнер до 1600 px по центру; основная колонка `1fr`, правая 360 px, зазор 24. Лента — `auto-fill minmax(280px, 1fr)`, 3 колонки на 1440 и 3–4 на 1920. Правая колонка `sticky`, её высота не превышает окно. На телефоне одна колонка, истории друзей заменяют боковую колонку, нижняя навигация резервирует место под себя.

**Состояния.**
- *Загрузка*: скелетоны постер-карточек; сайдбар — скелетоны строк.
- *Пусто*: «Продолжить» — спроектированная плитка («Пока пусто», что делать, «Найти видео»); лента — State «Пока нет открытых комнат» с действием; друзья — State «В сети пока никого».
- *Ошибка*: State `error` с причиной и «Повторить загрузку»; ошибка ленты не вытесняет остальной экран.
- *Частично*: у «Продолжить» нет длительности — полосы прогресса нет, а не нулевая.
- *Нет прав / гость*: вкладка «Друзья» предлагает войти; карточка входа заменяет «Продолжить».
- *Комната заполнена*: карточка не кликабельна, бейдж «Комната заполнена».

**Что убрано и почему.** Строка «чипов» со статистикой над плитками (шум над главным) — честные цифры переехали вниз правой колонки. Истории друзей на десктопе (дублируют колонку друзей). Три акцента (янтарь, малина, мята) — остался один.

**Данные.** Постер — миниатюра из метаданных, иначе градиент по категории. В каталоге нет длительности и ведущего, их не рисуем.
