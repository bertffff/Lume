# Lume — дизайн-система (v1)

Единственный источник правды по виду. Код: `apps/web/src/ds/` (токены, примитивы), галерея — `/__design` (только dev).

## Принципы

1. **Роли, а не значения.** Компонент знает `--ds-surface-2`, а не `#1E1A16`. Значения живут только в `ds/tokens/*.css`.
2. **Один акцент на экране.** Акцент = главное действие, активное состояние, прогресс. Семантические цвета (success/warn/danger/info) — только статусы: точка, иконка, строка текста. Заливать ими поверхности нельзя. Цвета людей (аватары) — идентичность, не акцент.
3. **Иерархия через поверхность и текст, не через цвет.** Три уровня текста, три уровня поверхности, одна рамка.
4. **Состояния — часть компонента.** Пусто, ошибка, загрузка, нет прав проектируются вместе с экраном.
5. **Три стиля = три личности над одной структурой токенов.** Не перекраска: меняются гарнитуры, радиусы, плотность, поверхность, **и раскладка экранов** (см. таблицу).

## Токены

| Группа | Роли |
| --- | --- |
| Поверхность | `bg`, `surface-1`, `surface-2`, `surface-3`, `overlay`, `scrim`, `stage` |
| Текст | `text-primary`, `text-secondary`, `text-tertiary`, `text-on-accent` |
| Граница | `border`, `border-strong`, `focus` |
| Акцент | `accent`, `accent-hover`, `accent-text`, `accent-soft` |
| Статусы | `success`, `warn`, `danger`, `info` (+ `-soft`) |
| Люди | `person-1…8` + `person-1…8-ink` |
| Активность | `heat-0…4` — производные от акцента через `color-mix` |
| Размер | сетка 4/8: `space-1…16` = 4 8 12 16 24 32 48 64 |
| Радиус | `radius-control`, `radius-card`, `radius-sheet`, `radius-chip`, `radius-pill` |
| Тип | `font-display`, `font-text`, `font-mono`; `fs-caption 12`, `fs-small 14`, `fs-body 16`, `fs-title 20`, `fs-headline 28`, `fs-display 40` |
| Движение | `dur-fast 120`, `dur-base 200`, `dur-slow 320`; `ease-standard`, `ease-emphasized` |
| Плотность | `control-sm/md/lg` (32/40/48), на `pointer: coarse` — не ниже 44 |
| Личность | `icon-stroke`, `glow`, `surface-blur`, `border-w` |

Правила: основной текст ≥ 14 px, 12 px — только мета (время, подпись). Контраст текста ≥ 4.5:1, иконок и границ состояния ≥ 3:1 — проверяет `tokens.test.ts` по всем 6 сочетаниям «стиль × тема». Иконки — только `lucide-react` через `<Icon>` (16/20/24).

## Три личности

| | Кинозал | Gruvbox | TeleRave-v2 |
| --- | --- | --- | --- |
| Характер | Тёплый, кинематографичный, воздушный | Настоящий terminal/tmux | Ночной клуб, стекло и свечение |
| Палитра | Тёплый уголь/бумага + янтарь | Официальный Gruvbox dark hard / light cream, акцент yellow | Индиго-ночь/лаванда + фиолетовый |
| Шрифты | Geologica (заголовки) + Onest | JetBrains Mono везде | Onest + заголовочный (уточняется) |
| Форма | радиус 8/16/24, тени мягкие | радиус 0–2, рамка 1px везде, без теней | радиус 12/20/28, стекло + свечение |
| Плотность | просторная | компактная (tmux-плитки) | средняя |
| Главная | Приветствие → [Продолжить · Создать · Войти] → вертикальная лента; справа друзья и виджеты | Таб-бар `0 home / 1 rooms`; плитки: сессии, буфер просмотра, друзья, `:new`, `:join`, вклад; статусная строка снизу | Хаб как в legacy: быстрый вход сверху, «Продолжить», активность друзей лентой, каталог на этой же странице |
| Комната | Сцена + одна полоса; голос и мини-очередь под ней; справа док «Чат / Люди / Очередь» | Сцена и очередь слева; чат и голос справа; нижняя строка `NORMAL \| lume/…` | Приоритет плеера, рейл справа, нижняя панель на мобильном |

## Правила кода

- CSS Modules рядом с компонентом, только токены. `!important` и инлайн-`style` запрещены; скрипт `scripts/check-ds.mjs` в `pnpm lint`.
- Модуль ≤ 300 строк. Экран = папка, собранная из примитивов `ds`.
- Старые `layout.css`, `room.css`, `src/ui/*` и токены `--lume-*`, `--s1…` удаляются по мере миграции экранов; к концу — полностью.
